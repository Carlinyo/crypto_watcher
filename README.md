# Crypto Signal Watcher

Следит за 15 крупнейшими криптовалютами (или за выбранными вами) круглосуточно и присылает уведомление, когда по совокупности
анализа складывается хорошая цена для покупки или продажи. Все уведомления приходят на почту, а сигналы
ПОКУПКА и ПРОДАЖА дополнительно дублируются по SMS. В каждом есть зона входа, стоп, две цели и
соотношение прибыль/риск.

## Какие монеты отслеживаются

По умолчанию (`SYMBOLS=auto`) раз в сутки программа сама выбирает **топ-15 по капитализации и объёму**:

1. Берёт 60 крупнейших монет по капитализации с CoinGecko.
2. Убирает стейблкоины (USDT, USDC, USDe…), обёрнутые и стейкинговые токены (WBTC, stETH…), токены золота.
3. Оставляет только монеты с парой к USDT на Binance.
4. Ранжирует по сумме мест: по капитализации и по объёму торгов за сутки (50/50), берёт 15 лучших.

При запуске и при каждом изменении состава приходит письмо со списком. Если CoinGecko
недоступен, рейтинг строится по объёму на Binance; если недоступна сеть — используется последний
сохранённый список. Размер топа — `TOP_N`, исключения — `EXCLUDE=doge,pepe`, свой фиксированный
список — `SYMBOLS=BTCUSDT,ETHUSDT`. Разово: `node index.js --top 10` или `node index.js SOLUSDT`.

## Что анализируется

| Блок | Что считается | Вес |
|---|---|---|
| 1. Зоны крупных торгов | Профиль объёма: POC, Value Area, узлы высокого и низкого объёма, свинг-уровни | 20% |
| 2. Тренд | EMA 20/50/200, наклон EMA50, ADX/DI, подтверждение на старшем таймфрейме | 25% |
| 3. Открытый интерес и киты | OI против цены, фандинг, соотношение лонгов и шортов, тейкеры, дельта объёма (CVD), китовые покупки и продажи за 4 часа | 20% |
| 3. Индикаторы | RSI, MACD, полосы Боллинджера (и сжатие), OBV, всплески объёма | 15% |
| 4. Паттерны | Поглощения, молот, звёзды, дивергенции RSI, двойное дно и вершина, структура HH/HL, пробои | 10% |
| 5. Новости | RSS Cointelegraph, CoinDesk, Decrypt (+ CryptoPanic), индекс страха и жадности | 10% |

Если итоговая оценка проходит порог (0.35), приходит сигнал ПОКУПКА или ПРОДАЖА. Если прибыль/риск
хуже 1.5, сигнал понижается до «готовиться» и указывается зона, где стоит ждать цену.
Веса и пороги меняются в `config.js`.

## 🐋 Отслеживание китов

Параллельно с анализом программа в реальном времени слушает **все сделки** по каждой монете на
Binance (спот и фьючерсы) и присылает письмо, когда кит покупает:

- **Крупный ордер** — одна рыночная покупка больше порога. Части одного ордера, которые прошли по
  нескольким уровням стакана, склеиваются в одну сделку.
- **Покупка частями** — 3+ заметные покупки за 10 минут на сумму от трёх порогов. Так киты прячут
  крупный набор позиции.

Порог свой для каждой монеты: 0.05% суточного объёма, но не меньше $250K и не больше $5M.
Например, для BTC это около $1–5M, для монет поменьше — $250K. Настраивается в `.env`.

В письме: сумма, количество монет, средняя цена, во сколько раз сделка больше порога, сколько
китовых денег зашло и вышло за последний час, и совпадает ли действие кита с текущим анализом.
По одной монете письмо приходит не чаще раза в 30 минут, но кит вдвое крупнее предыдущего
приходит сразу. Крупные продажи по умолчанию не присылаются (`WHALE_SELLS=1`, чтобы включить),
но и покупки, и продажи китов за 4 часа учитываются в блоке 3 анализа.

Ограничение: видны только сделки на Binance. Переводы между кошельками в блокчейне и сделки на
других биржах сюда не попадают.

## Какие уведомления куда приходят

| Событие | Почта | SMS |
|---|---|---|
| ПОКУПКА / ПРОДАЖА | полный отчёт | короткое сообщение |
| 🐋 Кит купил монету | ✓ | только при `WHALE_SMS=1` |
| Готовиться к покупке/продаже | ✓ | — |
| Нет данных 10 проверок подряд | ✓ | — |
| Запуск и смена списка монет | ✓ | — |

Один и тот же сигнал не повторяется чаще раза в 2 часа, в том числе после перезапуска.

## Шаг 1. Настройка уведомлений

Скопируйте `.env.example` в `.env`. Почта и номер телефона там уже вписаны, осталось добавить ключи.

**Почта (Gmail).** Gmail не пускает программы по обычному паролю, нужен «пароль приложения»:
1. Включите двухэтапную проверку в аккаунте Google.
2. Откройте https://myaccount.google.com/apppasswords, создайте пароль с любым названием.
3. Вставьте 16 символов (без пробелов) в `SMTP_PASS`.

**SMS (Twilio).** SMS в Армению — платная услуга:
1. Зарегистрируйтесь на https://www.twilio.com и купите номер с поддержкой SMS.
2. В консоли скопируйте Account SID и Auth Token в `TWILIO_SID` и `TWILIO_TOKEN`, номер — в `TWILIO_FROM`.
3. На пробном аккаунте подтвердите номер +37498628881 в разделе Verified Caller IDs и проверьте,
   что Армения включена в Messaging → Settings → Geo permissions.

Проверка (отправит тестовое письмо и одну тестовую SMS):

```bash
npm install
node index.js --test-notify
```

## Шаг 2. Деплой на сервер (работает 24/7)

Нужен любой VPS с Linux, хватит самого маленького (1 vCPU, 512 МБ–1 ГБ RAM), например Hetzner,
DigitalOcean или бесплатный Oracle Cloud Free Tier.
**Важно:** выбирайте сервер в Европе или Азии. Binance блокирует запросы с IP-адресов США.

### Вариант А — Docker (рекомендуется)

```bash
# на сервере
sudo apt update && sudo apt install -y docker.io docker-compose-v2
# загрузите папку проекта (scp, git или архив) и перейдите в неё
cd crypto-watcher
cp .env.example .env && nano .env        # заполнить ключи
sudo docker compose run --rm watcher node index.js --test-notify   # проверка уведомлений
sudo docker compose up -d --build        # запуск в фоне
sudo docker compose logs -f              # смотреть, что происходит (Ctrl+C — выйти из логов)
```

`restart: unless-stopped` перезапускает программу при сбое и после перезагрузки сервера.
Обновление: заменить файлы и выполнить `sudo docker compose up -d --build`.

### Вариант Б — без Docker (systemd)

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install -y nodejs
sudo useradd -r -s /usr/sbin/nologin crypto
sudo mkdir -p /opt/crypto-watcher && sudo cp -r ./* ./.env /opt/crypto-watcher/
cd /opt/crypto-watcher && sudo npm install --omit=optional && sudo chown -R crypto: .
sudo cp crypto-watcher.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now crypto-watcher
journalctl -u crypto-watcher -f          # логи
```

### Вариант В — pm2

```bash
npm i -g pm2 && npm install
pm2 start ecosystem.config.cjs && pm2 save && pm2 startup
```

## Локальный запуск

```bash
node index.js                   # наблюдение за парами из .env
node index.js SOLUSDT ETHUSDT --interval 15m --htf 1h
node index.js BTCUSDT --once    # один подробный отчёт
```

Флаги: `--top`, `--no-whales`, `--interval`, `--htf`, `--threshold`, `--poll` (секунды), `--verbose`, `--no-news`,
`--test-notify`. Если `api.binance.com` недоступен, замените в `config.js` адрес spot на
`https://data-api.binance.vision`.

## Важно

Это инструмент для анализа, а не гарантия прибыли. Сигналы основаны на правилах и могут ошибаться,
особенно на новостных движениях. Понаблюдайте за сигналами какое-то время и подстройте веса и порог
под свою монету и таймфрейм, прежде чем на них полагаться.
